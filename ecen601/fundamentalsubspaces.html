The four fundamental subspaces

A matrix A∈ℝm×n defines a linear map from ℝn to ℝm. Its four fundamental subspaces describe which input directions matter, which disappear, and which output directions are reachable.

A geometric picture

Input space → output space

x=xr+xn

Every input has a unique row-space component xr and nullspace component xn. These components are orthogonal.

Ax=Axr,Axn=0

The nullspace component disappears under A. Only the row-space component determines the output.

Ax∈ℛ(A)

Every output lies in the column space. The left nullspace contains the output-space directions orthogonal to every column of A.

Definitions

Let A:ℝn→ℝm. The notes use A∗ for the adjoint; over the real numbers, A∗=AT, the transpose used below. Vectors are column vectors.

  1. Range of A (column space of A)

    ℛ(A):={y∈ℝm:y=Ax,x∈ℝn}

    All outputs obtained as x ranges over the entire input space; equivalently, all linear combinations of the columns of A.

  2. Nullspace of A (kernel of A)

    𝒩(A):={x∈ℝn:Ax=0m}

    All input vectors sent to the zero vector in ℝm.

  3. Range of AT (row space of A)

    ℛ(AT):={x∈ℝn:x=ATy,y∈ℝm}

    All outputs of AT; equivalently, all linear combinations of the rows of A, written as column vectors in ℝn.

  4. Nullspace of AT (left nullspace of A)

    𝒩(AT):={y∈ℝm:ATy=0n}

    All vectors orthogonal to every column of A. Equivalently, yTA=0nT, which explains the word “left.”

Two orthogonal decompositions

ℝn=ℛ(AT)⊕⊥𝒩(A)

ℝm=ℛ(A)⊕⊥𝒩(AT)

dimℛ(AT)=r,dim𝒩(A)=n−r

dimℛ(A)=r,dim𝒩(AT)=m−r

Here r=rank(A) and ⊕⊥ denotes an orthogonal direct sum.

In particular, A maps its row space bijectively onto its column space: every attainable output has exactly one preimage in the row space.

    Reversing the map

    The pseudoinverse

    Given a target y, how can we recover an input x when y ∈ ℛ(A)—and what should an “inverse” return when y lies outside the range?

    If y is attainable, the bijection from the row space to the column space gives exactly one row-space input that maps to it. Other exact solutions differ by a nullspace vector. The row-space solution has the smallest Euclidean norm, because adding an orthogonal nullspace component can only increase its norm.

    If y is outside the range, no exact inverse exists at that target. First project it onto the column space:

    y=yr+yn,yr=Pℛ(A)y,yn∈𝒩(AT)

    Then invert yr within the row space. This gives the minimum-norm least-squares solution. Here yn is the left-nullspace component in the output space, while xn above belongs to the nullspace in the input space.

    ‖Ax−y‖2=‖Ax−yr‖2+‖yn‖2

    The two error components are orthogonal. Choosing an input with Ax = yr eliminates the first term, while the second term is unavoidable.

    Definition: minimum norm among least-squares solutions

    Following the supplied definition, let A: X → Y be a bounded linear operator between Hilbert spaces with closed range. For a given target y ∈ Y, define the pseudoinverse through two successive steps:

    1. First, find the best possible fit to y. Minimize the output error ‖Ax − y‖ over all inputs. Let S(y) be the set of all inputs attaining that smallest error. This set may contain one input or infinitely many. If y is attainable, S(y) is exactly the set of solutions of Ax = y. Otherwise, it is the set of least-squares solutions.

    2. Then, choose the shortest input among those best fits. Within S(y), select the unique vector with smallest norm and call it x̂. The pseudoinverse maps y to this particular vector:

      x^=A†y∈S(y)
      ‖x^‖≤‖x‖for everyx∈S(y)

    Example: If A = [1   0] and y = 2, every vector (2, t)T fits perfectly, so all of them belong to S(2). Among them, x̂ = (2, 0)T has the smallest norm. Thus A†2 = (2, 0)T.

    For real matrices with the standard Euclidean inner product, this is the Moore–Penrose pseudoinverse. Every matrix range is closed, so it exists uniquely for every matrix, including rectangular, rank-deficient, and zero matrices. We use A†; the notation A+ is also common.

    What changes with the shape of A?

    Shape constrains what is possible; rank determines what actually happens. In every case, an exact solution exists precisely when y ∈ ℛ(A). Its uniqueness requires 𝒩(A) = {0}.

    The Moore–Penrose characterization

    The unique matrix A† ∈ ℝn × m satisfies four equations:

    AA†A=A
    A†AA†=A†
    (AA†)T=AA†
    (A†A)T=A†A

    The dagger † denotes the Moore–Penrose pseudoinverse; the star * denotes the adjoint. For real matrices, the adjoint is the transpose. The projector identities use the pseudoinverse:

    Pcol=AA†,Pcoly=yr
    Prow=A†A,Prowx=xr

    Each projector is symmetric and idempotent: PT = P and P2 = P. The pseudoinverse reverses A between its column space and row space, and sends the entire left nullspace to zero.

    Using the adjoint gives different products. In general, AA* and A*A are not projectors. For example, if A = [2], both products equal [4], which is not idempotent. Here A† = [1/2], so both pseudoinverse products equal [1], the identity projector.

    Any rank: singular value decomposition

    Write A = QΣVT, using orthogonal matrices Q and V.

    A†=VΣ†QT

    Transpose the rectangular diagonal matrix Σ and replace each positive singular value σ by 1/σ; leave zeros as zeros. The symbols Q and V are separate from the RREF-derived basis U.

    Full column rank: r = n

    A†=(ATA)−1AT

    Here ATA is invertible. This includes tall matrices with independent columns.

    Full row rank: r = m

    A†=AT(AAT)−1

    Here AAT is invertible. This includes wide matrices with independent rows.
