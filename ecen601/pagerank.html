02 / Normalize a source column

Weight. Send. Collect.

A link from source j to destination i has a nonnegative weight wj→i. Divide each weight by that source’s total outgoing weight to obtain its transition probability Sij. The outgoing probabilities can differ.

Sij = wj→i / Σℓ wj→ℓ

Use this formula when the source’s total weight is positive. Zero weight means no link. If the total is zero, this demo sets Sij = 1/5 for every i.

For example, outgoing weights 4 and 1 become probabilities 0.8 and 0.2: the source sends 80% and 20% of its link-following score along those links. Destination i collects αSijpk,j from every source j, then adds its teleportation probability.

The column sums of S are 1, so multiplication preserves total probability. Uniform teleportation remains a separate choice; it does not require uniform outgoing link probabilities.

pk+1 = Gpk
= αSpk + (1 − α)u

This second form assumes Σᵢ pk,i = 1.

04 / Recognize the fixed point

The vector that stays.

Repeated multiplication is the power method. At equilibrium, applying G returns the same probability vector.

Gp* = 1 · p*

A right eigenvector of G, with eigenvalue λ = 1.

G
The Google transition matrix, with columns summing to 1.
p*
The PageRank vector, normalized so its entries sum to 1.
p*i
The long-run fraction of steps a random surfer spends on page i.

With uniform teleportation and 0 ≤ α < 1, every entry of G is positive. There is a unique stationary probability vector, and power iteration converges to it from any starting probability vector.

See how power iteration finds this vector and why the error shrinks below.

At α = 1, teleportation vanishes. Disconnected traps can make the stationary vector nonunique; periodic cycles can prevent iteration from converging. The slider stops at 0.99 to preserve the convergence guarantee.
Inside the algorithm / Power iteration

Multiply again. The error fades.

We know the eigenvalue we want: λ = 1. Power iteration finds its PageRank eigenvector by applying the weighted transition rule repeatedly, without computing every eigenvalue or forming powers of G explicitly.

How to compute the vector

  1. Choose a probability vector. Start with nonnegative scores that sum to 1. The laboratory uses p0 = u, so each page starts at 20%.
  2. Multiply once. Compute pk+1 = Gpk. Equivalently, multiply by the normalized weighted-link matrix S, scale by α, and add (1 − α)u.
  3. Repeat. After k updates, pk = Gkp0. Each update is one more step in the random surfer’s probability distribution.
  4. Stop when the residual is small. Check rk = ‖Gpk − pk‖1, the sum of absolute changes in the next update. The laboratory stops automatically when rk < 10−10.
p ← u
repeat:
    q ← αSp + (1 − α)u
    if sum(abs(q − p)) < tolerance:
        return p
    p ← q

General power iteration often normalizes after every multiplication. Here G preserves nonnegativity and the sum of the entries, so a probability vector stays normalized in exact arithmetic. Renormalization may be used to correct floating-point drift.

On a large web, compute αSp + (1 − α)u using the sparse link structure and the dangling-page rule. There is no need to store the dense teleportation matrix.

Why teleportation makes it converge

Take any two probability vectors p and q. They both sum to 1, so their uniform teleportation terms cancel when we subtract their next updates:

Gp − Gq = αS(p − q)

Because S has nonnegative entries and columns summing to 1, multiplying by S cannot increase the 1-norm of a vector. Therefore,

‖Gp − Gq‖1 ≤ α‖p − q‖1

For 0 ≤ α < 1, each update is a contraction on probability vectors.

This contraction guarantees one unique fixed probability vector p*. Taking q = p* shows that every starting probability vector converges to it:

‖pk − p*‖1 ≤ αk‖p0 − p*‖1

In eigenvalue terms, the λ = 1 component remains while all other eigenvalues of G satisfy |λ| ≤ α < 1. Their contributions decay with repeated multiplication. The contraction proof also works when G has no complete basis of eigenvectors.

A larger α gives a weaker worst-case convergence guarantee: 0.99 can require many more steps than 0.50. The actual rate also depends on the weighted graph.

How does the residual bound the error?

The triangle inequality and contraction give ‖p − p*‖1 ≤ ‖p − Gp‖1 + α‖p − p*‖1. Rearranging gives the bound below. A small residual is a stopping test; it is not itself the distance to the eigenvector.

A stopping test with an error guarantee

‖pk − p*‖1 ≤ rk / (1 − α)

The live laboratory residual and error bound appear here when JavaScript is enabled.

This is a conservative upper bound, not a measured error; live values use floating-point arithmetic. For example, at α = 0.85, a residual below 10⁻¹⁰ guarantees a 1-norm error below approximately 6.67 × 10⁻¹⁰. Return to the laboratory to change α and watch convergence.

05 / From importance to ordering

A score becomes
a ranking signal.

Sort the stationary scores from largest to smallest, and you get an ordering by link-based importance. The list beside this text always uses the equilibrium vector for the current web and α, even while the laboratory is still iterating.

In a simplified search engine, you could use that importance to help order pages relevant to a query. PageRank itself is independent of the query in this model.

Google Search uses many ranking systems and signals, including relevance and freshness. Google says PageRank has evolved and remains part of its core ranking systems. This lesson demonstrates a weighted PageRank model; the list is an illustration of PageRank ordering.
