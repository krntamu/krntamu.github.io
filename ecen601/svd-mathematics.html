The mathematics of SVD

Why does every matrix admit a singular value decomposition? We will construct the factors from an eigendecomposition and see exactly how the four fundamental subspaces determine the singular vectors.

01

The decomposition we will prove

Singular value decomposition

Let A∈ℂm×n have rank r, and set p=min(m,n). There exist unitary matrices U∈ℂm×m and V∈ℂn×n, and a rectangular diagonal matrix Σ∈ℝm×n, such that

A=UΣVH(1)
UHU=UUH=Im,VHV=VVH=In(2)

The diagonal entries of Σ are the singular values, ordered as

σ1≥⋯≥σr>0,σr+1=⋯=σp=0(3)

The positive chain is absent when r=0; the zero chain is absent when r=p. Every off-diagonal entry of Σ is zero. For a real matrix A, the factors can be chosen real, so U and V are orthogonal and the factorization is A=UΣVT.

The columns of V are the right singular vectors, living in the input space ℂn. The columns of U are the left singular vectors, living in the output space ℂm. Our task is to construct two orthonormal bases for which A acts by nonnegative coordinate scalings.

Find input directions

Use the orthonormal eigenvectors of AHA.

Find their images

Normalize the nonzero vectors Av_i to obtain the left singular vectors.

Complete the bases

Use the null spaces, then assemble the matrix identity.

02

A constructive proof

Step 1 Apply the spectral theorem to AHA

The matrix AHA is n×n even when A is rectangular. It is self-adjoint because

(AHA)H=AHA(4)

It is also positive semidefinite: for every input vector x_∈ℂn,

x_HAHAx_=(Ax_)H(Ax_)=‖Ax_‖2≥0(5)

By the spectral theorem, there is an orthonormal basis v_1,…,v_n with real eigenvalues λ1,…,λn satisfying

AHAv_i=λiv_iv_iHv_j=δijAHA=VΛVH(6)

Here V=[v_1⋯v_n] and Λ=diag(λ1,…,λn). Because each eigenvector has unit norm, its eigenvalue satisfies

λi=v_iHAHAv_i=‖Av_i‖2≥0(7)

Thus all these eigenvalues are nonnegative. Order the eigenvectors so that the eigenvalues are nonincreasing.

Step 2 Count the positive eigenvalues and define the singular values

We need to relate the number of positive eigenvalues to the rank of A. The crucial fact is that A and AHA have the same null space. One inclusion is immediate: Ax_=0_ implies AHAx_=0_. For the other direction,

AHAx_=0_⇒x_HAHAx_=0⇒‖Ax_‖2=0⇒Ax_=0_(8)

Consequently, 𝒩(AHA)=𝒩(A). Both matrices have n columns, so rank–nullity gives

rank(AHA)=n−dim𝒩(AHA)=n−dim𝒩(A)=r(9)

A diagonalizable matrix has rank equal to the number of nonzero eigenvalues. Since these eigenvalues are nonnegative, exactly r are positive:

λ1≥⋯≥λr>0,λr+1=⋯=λn=0(10)

Empty index ranges are omitted, as in the theorem. For 1≤i≤r, define

σi=λi(11)

There are p=min(m,n) singular values in the usual list: r positive values and p−r zeros. For a wide matrix, AHA has n eigenvalues, but the singular-value list has only m entries. The remaining n−m eigenvalues are additional zeros.

For every zero-eigenvalue direction, Step 1 also gives ‖Av_i‖2=0. Therefore

Av_i=0_,r<i≤n(12)

The last n−r right singular vectors form an orthonormal basis for 𝒩(A). They are precisely the input directions that disappear.

Step 3 Construct the left singular vectors

For each positive singular value, define a vector in the output space by normalizing the image of its right singular vector:

u_i=Av_iσi,1≤i≤r(13)

This is legitimate because σi>0. The normalization has a purpose: Step 1 showed that ‖Av_i‖=σi, so each newly defined vector has unit norm.

We must also prove that different left singular vectors are orthogonal. For i,j≤r, compute

u_iHu_j=v_iHAHAv_jσiσj=λjv_iHv_jσiσj=λjδijσiσj(14)

When i≠j, the numerator is zero. When i=j, the expression is λiσi2=1. Hence u_1,…,u_r is an orthonormal set.

Handle zero singular values separately. The formula u_i=Av_iσi is used only for positive singular values. Whenever σi=0, its associated image Av_i is also zero; division would be undefined. We will obtain the remaining left singular vectors by completing an orthonormal basis.

Step 4 Identify the column space and complete U

Because the right singular vectors form an orthonormal basis of the entire input space, every input vector has the expansion

x_=∑i=1nv_i(v_iHx_)(15)

Apply A, use Av_i=σiu_i for the positive directions, and use Av_i=0_ for the null directions:

Ax_=∑i=1rσiu_i(v_iHx_)(16)

This proves that every output of A lies in span{u_1,…,u_r}. Conversely, every u_i in this set is itself an image under A, since u_i=A(v_iσi). Therefore

ℛ(A)=span{u_1,…,u_r}(17)

The known fundamental-subspace relationship ℛ(A)⊥=𝒩(AH) now supplies the missing directions. Choose any orthonormal basis u_r+1,…,u_m for 𝒩(AH). Its dimension is m−r. Together with the first r vectors, these columns form an orthonormal basis of ℂm. Thus

U=[u_1⋯u_ru_r+1⋯u_m],UHU=Im(18)

When r=m, the column space already fills the output space and no extra columns are needed. Orthonormal completion can be performed with Gram–Schmidt on any basis of the left null space.

Step 5 Assemble the factorization

Define the m×n matrix Σ by

Σij={σiif i=j≤r0otherwise.(19)

Compare the columns of AV and UΣ. Their first r columns are σiu_i, and all remaining columns are the zero vector in the output space. Therefore

AV=[σ1u_1⋯σru_r0_⋯0_]=UΣ(20)

Empty column groups are omitted: there is no positive group when r = 0 and no zero group when r = n. Right-multiplying by VH and using VVH=In gives

A=AVVH=UΣVH(21)

All dimensions agree:

Am × n=Um × mΣm × nVHn × n(22)

We have constructed unitary U and V, a nonnegative rectangular diagonal Σ, and the required equality for every matrix A. This completes the proof. When A is real, start with a real orthonormal eigenbasis of AᵀA and choose a real basis of the left null space. Every constructed factor is then real.

□

The zero matrix is included. If r=0, there are no positive singular values and no normalization step. Choose any orthonormal bases for the input and output spaces, set Σ=0m×n, and obtain A=UΣVH=0m×n. Every sum over the positive singular directions is then an empty sum, equal to zero.

Step 6 Verify the matching eigendecomposition of AAH

The construction also explains why left singular vectors can be found from AAH. For i≤r,

AAHu_i=A(AHA)v_iσi=λiAv_iσi=λiu_i=σi2u_i(23)

For each completed direction in 𝒩(AH), AHu_i=0_ and hence AAHu_i=0_. Thus the two self-adjoint products have full eigendecompositions

AHA=V(ΣHΣ)VHAAH=U(ΣΣH)UH(24)

They have the same r positive eigenvalues σ12,…,σr2, with n−r and m−r zero eigenvalues, respectively. In particular, the paired positive singular vectors satisfy

Av_i=σiu_i,AHu_i=σiv_i(25)

The second identity follows directly from AHu_i=AHAv_iσi=σiv_i. These pairings are why the left and right singular vectors must be chosen consistently.

03

Where the four fundamental subspaces appear

The proof has identified orthonormal bases for all four subspaces. For complex matrices, the row-space counterpart is ℛ(AH), represented by column vectors in the input space. In the real case, this is the usual row space written as column vectors.

The last n−r columns of V span 𝒩(A). Therefore its first r columns span the orthogonal complement 𝒩(A)⊥=ℛ(AH). The construction of U supplies the corresponding bases in the output space.

SubspaceDimensionOrthonormal basis from the SVD
Column space ℛ(A)ru_1,…,u_r
Left null space 𝒩(AH)m−ru_r+1,…,u_m
Row-space counterpart ℛ(AH)rv_1,…,v_r
Null space 𝒩(A)n−rv_r+1,…,v_n

The rows of this table also cover zero-dimensional subspaces: the corresponding basis list is empty. The input decomposes orthogonally into ℂn=ℛ(AH)⊕𝒩(A), and the output decomposes into ℂm=ℛ(A)⊕𝒩(AH).

What A actually does.

On ℛ(AH), A sends each v_i to σiu_i. It annihilates 𝒩(A). Every output is in ℛ(A), so no output has a component in 𝒩(AH).

The arbitrary-input calculation in Step 4 is also the outer-product decomposition:

A=∑i=1rσiu_iv_iH(26)

Each u_iv_iH is an m×n matrix. Acting on x_, it first extracts the scalar coordinate v_iHx_ and then places that amount along u_i. Multiplication by σi supplies the stretch. This is the mathematical basis of the outer-product display on the first page.

04

Full, economy, and rank-compact forms

The proof constructs the full bases. The two smaller versions remove columns and rows that contribute only zeros to the product.

Economy form

Let p=min(m,n). Keep the first p columns of U and V and all p singular values:

A=UpΣpVpH(27)

Dimensions: (m×p)(p×p)(p×n). Zero singular values may remain. The factors Up and Vp have orthonormal columns.

Rank-compact form

Keep only the r positive singular values and their corresponding left and right singular vectors:

A=UrΣrVrH(28)

Dimensions: (m×r)(r×r)(r×n). The diagonal Σr is invertible when r>0. For the zero matrix, use the empty-sum interpretation.

The factors need not be unique. The singular values are fixed by A, but singular vectors admit sign changes in the real case and common phase changes in the complex case. Within a repeated positive singular value, the corresponding columns of U and V can be changed by the same unitary mixing. Bases of the two null spaces can be chosen independently. The construction u_i=Av_iσi keeps every positive pair aligned.
05

A worked rectangular, rank-deficient example

Take a real 3×2 matrix whose two columns are identical:

A=[112222](29)

Its rank is one. This example exposes both the zero singular value and the extra output-space directions that a full U must contain.

Find the right singular vectors

ATA=[9999](30)

An orthonormal eigenbasis is

v_1=12[11],λ1=18v_2=12[1−1],λ2=0(31)

Thus σ1=32 and σ2=0. Also Av_2=0_, so v_2 spans the input null space.

Normalize the nonzero image, then complete the output basis

u_1=Av_1σ1=13[122](32)

For the remaining columns of U, choose

u_2=12[01−1],u_3=132[−411](33)

Each has unit norm, and their inner products with one another and with u_1 are zero. Both also satisfy ATu_j=0_ for j=2,3. They therefore span the two-dimensional left null space.

Write the full SVD

U=[130−432231213223−12132]Σ=[3200000],VT=12[111−1](34)

Here U is 3×3, Σ is 3×2, and V is 2×2. The economy form keeps u_1,u_2 and both singular values. The rank-compact form keeps only u_1,σ1,v_1.

Verify the product as one outer product

A=σ1u_1v_1T=(32)(13[122])(12[11])=[112222](35)

For an arbitrary input x_=[x1x2], the map is

Ax_=(x1+x2)[122](36)

Only the sum of the two input coordinates matters. The difference direction v_2 disappears, and every output lies on the line spanned by u_1. A two-dimensional input grid therefore collapses to a line in three-dimensional space.

The proof in one chain

  1. Diagonalize the self-adjoint positive semidefinite matrix AHA to obtain an orthonormal input basis.
  2. The r positive eigenvalues give σi=λi; the remaining eigenvectors lie in 𝒩(A).
  3. For the positive directions, set u_i=Av_iσi. The eigenvector equations prove that these images are orthonormal.
  4. These r vectors span ℛ(A). Complete them using an orthonormal basis of 𝒩(AH).
  5. Now AV=UΣ column by column, so A=UΣVH.

The SVD expresses a linear map in input and output orthonormal bases adapted to its fundamental subspaces. In these coordinates, all that remains is nonnegative scaling along r independent directions, with the null-space directions sent to zero.
